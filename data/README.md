# Data

The raw file is not included in this repo.

1. Download the **Mobile Games A/B Testing (Cookie Cats)** dataset from Kaggle. Check its page for the licence.
2. Save the file as `data/raw/cookie_cats.csv`.

Columns: `userid`, `version` (`gate_30` or `gate_40`), `sum_gamerounds` (rounds played in the first 14 days), `retention_1` and `retention_7` (whether the player came back 1 and 7 days after install).
